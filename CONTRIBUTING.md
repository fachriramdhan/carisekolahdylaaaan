# Kontribusi ke EduMap Transit

Terima kasih telah tertarik untuk berkontribusi pada EduMap Transit! Kami sangat menghargai bantuan Anda untuk membuat aplikasi ini lebih baik bagi siswa di Jakarta.

## Cara Berkontribusi

### 1. Melaporkan Bug
Jika Anda menemukan kesalahan teknis atau data sekolah yang tidak akurat:
- Buka [Issues](https://github.com/username/edumap-transit/issues).
- Jelaskan bug secara detail, termasuk langkah-langkah untuk mereproduksinya.

### 2. Menambah Data Sekolah
Jika ada sekolah yang belum terdaftar:
- Edit file `src/data/schools.json`.
- Pastikan koordinat (lat/lng) akurat (bisa dicek melalui Google Maps).
- Tambahkan informasi angkutan umum yang relevan.

### 3. Pengembangan Fitur
- Fork repository ini.
- Buat branch baru (`git checkout -b fitur-baru`).
- Lakukan perubahan dan commit (`git commit -m 'Menambah fitur X'`).
- Push ke branch Anda (`git push origin fitur-baru`).
- Buat Pull Request.

## Standar Kode
- Gunakan TypeScript untuk keamanan tipe data.
- Gunakan Tailwind CSS untuk styling agar konsisten dengan desain yang ada.
- Pastikan aplikasi tetap responsif di perangkat mobile.
